# 🎂 Bestie Birthday Website

An interactive birthday surprise website I built for my best friend, with a heartfelt letter, a funny twist and plenty of confetti.

**🔗 Live demo:** https://favouregbunine.github.io/Bestie/

## ✨ Features
- Intro screen that fades into the main page
- Birthday letter and photo section
- "Reasons you're stuck with me" cards
- Interactive "reveal" section with a joke contract
- Confetti and floating hearts animations
- Fully responsive, works on phones

## 🛠️ Built with
- HTML5
- CSS3 (animations, grid, responsive design)
- JavaScript (DOM manipulation, events)
- Hosted on GitHub Pages

## 💡 What I learned
- Connecting HTML, CSS and JS files properly
- Building interactive UI with JavaScript events
- Deploying a project with GitHub Pages, all from my phone 📱
